# Security and contact

## Reporting something about this repository

If a file here is unlawful, infringing, or outside the scope described in
[`DISCLAIMER.md`](DISCLAIMER.md), open an issue titled `scope` or write to the address on my
GitHub profile (`oniz93`). Substantiated requests are reviewed and the file removed.

## What this repository will not do

It will not host material that could be used to modify a console, and it will not become a
disclosure channel for platform research. Reports that a file here goes beyond phase-level
status are treated as defects and fixed by removing the file.

## What I am not offering

No bounty programme, no responsible-disclosure intake for third-party findings, and no
support for using this repository to do anything. It is a status page.
