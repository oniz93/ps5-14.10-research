## 1. Object level: the real class, compiled with the build's own command line

The build's DEFINES/INCLUDES/FLAGS were lifted verbatim from build.ninja's statement for
Source/WebCore/CMakeFiles/WebCore.dir/page/UserMessageHandler.cpp.o (same target, same
flags; the object for CSS/Canvas TUs is not on disk in this build dir, so the only way to
get this TU is to compile it). Command actually run inside `distrobox enter wk`:

  g++ <DEFINES> <INCLUDES> <FLAGS> -c .../Source/WebCore/html/canvas/CanvasRenderingContext2D.cpp \
      -o /tmp/isoheap/ctx2d_real.o

  DEFINES = -DBUILDING_GTK__=1 -DBUILDING_WEBKIT=1 -DBUILDING_WITH_CMAKE=1 -DBUILDING_WebCore
            -DGETTEXT_PACKAGE=\"WebKitGTK-4.1\" -DHAVE_CONFIG_H=1 -DJSC_GLIB_API_ENABLED
            -DPAS_BMALLOC=1 -DSTATICALLY_LINKED_WITH_PAL
  FLAGS   = -fno-omit-frame-pointer -fno-optimize-sibling-calls -O1 -g -DNDEBUG -std=c++20
            -fPIC -fvisibility=hidden -fsanitize=address -fno-exceptions -fno-rtti -pthread ...
