# Contributing

This repository does not accept code, tooling, data, or research contributions — the
publication path only carries curated status text, so a pull request cannot add anything else.

## What is useful

- **Corrections to this page.** Wrong phase state, a broken link, an unclear sentence.
- **Scope reports.** If something here appears to go beyond phase-level status, say so; that is
  a defect and it will be removed.

## What will be closed without discussion

Pull requests that add scripts, logs, addresses, memory layout, firmware, images, or instructions.
Issues that ask how to modify a console, how to run unsigned code on one, or where to find the
private notebook.

## Process

Open an issue first. If a change to the status text is warranted it is made in the private
notebook and reaches this page through the publication path, with the review described in
[`DISCLAIMER.md`](DISCLAIMER.md) §3.
